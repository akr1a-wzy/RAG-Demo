02 / 架构

按问题选择路径，让证据约束回答。

财务与行情共用别名、短年份和受限追问解析，保留未知条件并前置检查能力；员工走RAG，核准字段直接查目录，行情走工具。

员工问答生成草稿
  1. 恢复请求公司、年份与主体
  2. 混合检索BM25 + 向量 + RRF
  3. GPU重排20候选 / Top5
  4. 生成与校验DeepSeek + 引用绑定
财务 / 公告原文事实或核准计算
  1. 受限意图解析字段、期间与操作
  2. 审核字段目录PDF哈希与单元格证据
  3. 直接列值 / 计算Decimal与口径规则
  4. 原文引用保留年度、单位和物理页

03 / 工程取舍

真正需要处理的，是“命中之后仍会答错”。

A

数字出现，不等于事实成立。

同一表格中同时出现本年、上年与多种单位，仅验证数字是否在来源中，会放过错列回答。将指标、年度列、数值、局部单位与主体绑定，复杂表头继续隔离。

取舍

限制可回答范围，换取受支持字段的证据可核对性。

B

来源页补回后，子公司表却排在首位。

中国神华营收题正确第8页未进20候选；摘要补召回又把第124页关联财务公司（控股股东的子公司）4,251百万元排到首位。收紧标题边界并排除财务公司子表、季度表后，正确第8页升至首位。

取舍

这是已知检索路径修复，不能由页码命中推断答案正确；当时尚未生成回答。

C

统一解析年份、别名和追问条件。

“25年最高股价”曾误返最新价，“总营收”曾被拒。财务与行情现共用查询理解，保留未知限定并在取数前检查能力；总营收按营业收入口径明示。

取舍

确定性规则便于追踪，但覆盖有限。年度最高/最低价仍未实现，当前明确提示不支持。

后续85题为已知业务回归，不能和此前83题或54场景直接作同分母提升比较。源码包中的评测摘要提供报告角色和路径。

最近一次完整代码测试记录为本机607项通过，非公开CI；统一查询理解已知场景本机16/16、公网6/6，0生成，两处共2次行情取数。免登录切换后匿名HTTPS检查23/23，0生成。以上分别来自历史报告，本轮未重跑业务或封存验收，不是任意用户问题上的答案准确率。

05 / 范围

把当前能力与后续计划分开。

当前可体验

  • 公开年报与公告的原文、物理页引用。
  • 核准财务字段、公司比较、换算和受支持的同比计算。
  • 员工草稿、主体澄清、无证据拒答及会话追问。
  • 最新行情估值、最近交易日前复权日K和显式快照回放。

需要保留的限制

  • 全语料复杂表头与任意财务语义尚未验收。
  • 2024财务值来自2025年报比较列，保留重述口径。
  • 年度最高/最低价与历史时点行情未实现；不会用最新报价代替。
  • 员工生成保持草稿；本机与隧道需持续运行。

最新运行版本：tencent-market-qfq-v1.4-query-understanding；共用理解层query-understanding-v1。原始失败报告与旧对话保留，历史错误回答不会被回写成新结果。
